# Nike Buyer Persona — DM 105

A one-page fictional Nike customer persona created for BYU–Idaho DM 105: Introduction to Digital Marketing, Discussion 1.7.

## Publish with GitHub Pages

1. Upload `index.html` to the root of the GitHub repository.
2. Open **Settings → Pages**.
3. Under **Build and deployment**, choose **Deploy from a branch**.
4. Select branch `main` and folder `/ (root)`, then save.
5. Wait a few minutes for the published website link to appear in Settings → Pages.

The customer persona is fictional and is for coursework purposes.
